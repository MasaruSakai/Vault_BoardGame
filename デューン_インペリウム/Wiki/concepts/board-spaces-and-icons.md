# ボードのマスとアイコン

## マスの読み方

ボードのマス左上にあるアイコンは、代行者の派遣に使えるカードの派遣アイコンを示す。マスの矢印は、左または上に示されたコストを支払うと、右または下の効果を得られることを示す。コストは任意で、支払わなければその効果を得ない。

一度、代行者を置いたマスは占有される。通常は別の代行者を置けないが、スパイの潜入やスパイ派遣アイコンによって例外が生じる。

## 主要なマスの分類

- **派閥マス** — 対応する影響力を1上げる。
- **資源マス** — 水、香料、ソラリ、説得力などを得る。
- **紛争マス** — 部隊を招集・進軍し、紛争へ参加する。
- **策謀マス** — 策謀カードを引く。
- **スパイ関連マス** — スパイを置く、回収する、または観測所へ接続する。
- **メイカーマス** — 代行者がいない場合、産出フェイズに香料が蓄積する。
- **重要拠点** — 紛争に勝つと占拠マーカーを置き、以後の派遣へボーナスを与える。

## 資源・状態アイコン

| 表記 | 意味 |
|---|---|
| 水滴 | 水を得る／支払う |
| 金色の球 | 香料を得る／支払う |
| 灰色の円 | ソラリを得る／支払う |
| 緑・青・黄の派閥記号 | 対応する派閥の影響力 |
| キューブ | 部隊を1個招集 |
| 赤刃 | 戦力を1加える |
| 交差剣 | 紛争エリアまたは戦闘関連 |
| 砂虫 | 砂虫を召喚して戦場へ置く |
| メイカーフック | 砂虫召喚の条件 |
| 防嵐壁破壊 | 防嵐壁を取り除く |
| スパイ | 観測所へスパイを置く |
| スパイ回収 | 観測所から自分のスパイを基地へ戻す |
| 策謀 | 策謀カードを得る／使う |
| 勝利点 | スコアトラックを動かす |
| 破棄 | カードをデッキから取り除く |

図柄が文章効果と組み合わされている場合は、カードまたはボードに印刷された条件を優先する。アイコンの詳細はルールブック裏表紙の一覧と、プレイ中のカード本文を併用する。
