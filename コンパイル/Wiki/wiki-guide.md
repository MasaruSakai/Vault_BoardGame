# 読み方

1. まず[入口](index.md)で質問の分野を選ぶ。
2. ルールの確認は`concepts/`または[Rules FAQ](faq/rules-faq.md)から始める。
3. 数値・例外・カード文面は、各ページの`source_files`と[ルール画像の対応表](sources/source-page-map.md)で原典へ戻る。
4. 実戦上の評価・コンボ・ドラフト案は、ルールと区別して`strategy/`を参照する。

# 情報の層

- `../Sources/`: 人間が保管するルール画像。ルール判断の優先根拠。
- `Wiki/concepts/`: 画像から整理したルールと用語。
- `Wiki/faq/`: BGG Rulesの質問・回答をルールシートと照合したもの。
- `Wiki/strategy/`: BGG Strategyのコミュニティ議論。公式ルールではない。
- `Wiki/sources/`: 外部リンク、取得時点、対応範囲、読み取り上の注意。

# 回答時の原則

- ルール画像とBGG投稿が異なる場合は、ルール画像を優先する。
- デザイナー投稿は有力な補足だが、カード／ルール本文を置き換えない。
- Strategyの「強い」「弱い」は環境依存の意見として扱い、確定ルールと混ぜない。
- BGG本文が取得できなかったトピックは推測で補完しない。
