## 原典画像について

市販ゲームのルールブック画像は著作権保護された素材であるため、この公開リポジトリには収録しません。ローカルでは次の場所へ保存すると、OKFノート内の出典リンクを利用できます。

```text
ClankCatacomb/OKF/references/source-pages/rulebook-page-01.jpg
...
ClankCatacomb/OKF/references/source-pages/rulebook-page-18.jpg
```

OKFノートは画像がなくても検索・閲覧できます。アイコンの形、細かな数値、例外処理を確認する場合は、正規に入手したルールブックを参照してください。
