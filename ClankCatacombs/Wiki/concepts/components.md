# 主要コンポーネント

- クランク！ボード 1枚
- 開始時タイル 1枚
- 正方形タイル 28枚
- ドラゴンマーカー 1個
- ドラゴン袋 1個
- ドラゴンキューブ 24個
- プレイヤーキューブ（各色）
- クランク！キューブ（各色）
- 体力マーカー
- プレイヤーコマ
- 初期デッキを含む各種カード
- ダンジョン列カード用デッキ
- 予約カード用マーカー／領域
- アーティファクト、アイテム、偶像、囚人、猿の偶像などの各種トークン
- 市場タイルと市場アイテム
- 得点・報酬に用いるトークン類
- ルール説明書とリファレンスカード

# 用途別の見方

カードはプレイヤーのデッキと中央のダンジョン列を構成する。タイルは探索により追加され、通路・部屋・秘密・モンスターなどの状況を作る。色付きキューブは各プレイヤーのクランク！とダメージを追跡し、黒いドラゴンキューブと共に袋へ入る。

各アイコンの実際の効果は[部屋・通路・タイル要素](tile-features.md)および[カードとアイテム早見表](card-and-item-reference.md)を参照。
