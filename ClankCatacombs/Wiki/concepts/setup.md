# 共通エリア

1. クランク！ボードを置く。
2. 開始時タイルを中央に置き、残りの正方形タイルを裏向きで混ぜて山にする。
3. ドラゴン袋と**黒いドラゴンキューブ24個**を準備する。キューブの個数は人数で変わらない。
4. 市場と購入可能な市場アイテムを準備する。
5. ダンジョン列カードを準備し、全員で使う共通の公開カード列を**6枚**作る。初期公開時にDragon Attackアイコンがあるカードは脇に置き、アイコンのない6枚がそろうまで補充する。
6. 常時獲得できる基本カードの山を分けて置く。
7. アーティファクトなど、探索で使うトークンを種類別に準備する。

# プレイヤーの準備

1. 色を選び、その色のプレイヤーコマ、体力マーカー、クランク！キューブを受け取る。
2. プレイヤーコマを開始地点へ置く。
3. 体力マーカーをクランク！ボードの体力トラックの開始位置へ置く。
4. 各自の初期デッキをよく混ぜて山札にする。
5. 初期手札を引く。
6. 開始プレイヤーと手番順を決め、初期クランク！を手番順に応じて配置する（1番手3個、2番手2個、3・4番手0個）。怒りマーカーの初期位置はプレイ人数で指定された位置に置く。

# 開始前の確認

- タイル山とカード山が裏向きである。
- ダンジョン列が必要枚数公開されている。
- 各プレイヤーの色のキューブが混在していない。
- 市場アイテム、アーティファクト、秘密トークンが参照図に従って準備されている。
