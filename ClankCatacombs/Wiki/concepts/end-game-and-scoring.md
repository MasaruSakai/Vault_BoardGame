# 脱出

アーティファクトを所持してBasement（開始地点）へ戻ると脱出。脱出したプレイヤーはPawnを盤面から外し、Major Secret 20VPを受け、以後通常の探索手番を行わない。脱出後は列を補充し、残りのプレイヤーの手番だけが続く。

# ノックアウト

ダメージで体力が尽きるとノックアウトされる。地下深くで倒れた場合と、地上に近い安全圏まで戻っていた場合とでは、救出および得点資格が異なる。アーティファクトを獲得していない場合も最終得点に重大な影響がある。

# ゲーム終了

ゲームは、全プレイヤーが脱出またはKOした時点で終了する。脱出後のプレイヤーは通常手番を行わず、残りのプレイヤーは自分の手番を続ける。ドラゴン袋が攻撃後に空になった場合は、全員が脱出／KOするのを待たず即時終了し、残っているプレイヤーはKOになる。[ドラゴンの攻撃とダメージ](dragon-attacks-and-damage.md)を参照。

# 得点

得点資格を持つプレイヤーは、以下を合計する。

- 持ち帰ったアーティファクトの勝利点。
- 獲得したカードに記載された勝利点。
- 金貨。
- 秘密、偶像、囚人、市場アイテムなどに記載された勝利点。
- 脱出や生還に関するボーナス。

脱出／KO後の代替手番では、袋から4個（2人プレイは6個）を引く。これは怒りマーカーとDangerを無視する。

合計勝利点が最も高いプレイヤーが勝者となる。同点処理は原典14ページの記載に従う。
