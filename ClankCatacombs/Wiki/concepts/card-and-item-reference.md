# カードの読み方

カードには、獲得コスト、手番で得られるスキル・ブーツ・剣・クランク！、即時／条件付きテキスト、カード種別、勝利点などが示される。

- **仲間**: プレイヤーのデッキへ加わり、プレイ時に能力を提供する。
- **モンスター**: 剣を使って戦い、報酬を受け取る。通常は獲得してデッキへ入れない。
- **装置**: スキルを支払って効果を利用する。通常は獲得しない。
- **ドラゴン攻撃アイコン**: ダンジョン列への補充時に公開されると攻撃を誘発する。
- **到着／獲得時効果**: 公開時または獲得時に即座に処理する指示がある。

# アーティファクト

各アーティファクトには勝利点があり、プレイヤーは原則1つだけ持ち運ぶ。取得するとドラゴンの怒りが上昇する場合がある。Caravan／Backpackを購入すると運搬上限が1つ増え、同じ市場アイテムを複数買えば効果は累積する。

# 大小の秘密

秘密トークンは、回復、資源、金貨、得点、継続的な利点などを与える。即時に使うものと、必要な時に使えるもの、最終得点になるものを区別する。

# 市場アイテム

市場のある部屋で金貨を支払って購入する。鍵、背負い袋、王冠などは、移動制限の解除、追加アーティファクトの運搬、勝利点など固有の役割を持つ。

# 仲間と特殊カード

特定の仲間やカードは、同じ手番に他の仲間をプレイした場合など、条件を満たすと追加効果を得る。カード本文の条件を満たした時点で適用する。
