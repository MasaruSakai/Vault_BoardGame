# 目的

プレイヤーは盗賊となり、地下のカタコンベへ侵入する。探索中に宝物を集め、アーティファクトを1つ確保し、可能なら地上へ生還する。最終的に最も多くの勝利点を獲得したプレイヤーが勝者となる。

# ゲームの特徴

- 1～4人用。
- デッキ構築により、手番で使える能力を増やしていく。
- カタコンベはタイルを発見して徐々に広がるため、毎回異なる地形になる。
- 騒音を表す「クランク！」がドラゴンの攻撃時の被害リスクになる。
- 深く潜るほど価値ある報酬を得やすいが、脱出できない危険も増す。

# 根幹となる判断

ゲーム中は「より深く探索して得点を伸ばすか」「生還を優先して引き返すか」を継続的に判断する。手番の詳細は[手番の進行](turn-sequence.md)、終了条件は[ゲーム終了と得点計算](end-game-and-scoring.md)を参照。
