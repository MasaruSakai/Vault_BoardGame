# 発見が起こるとき

プレイヤーが、現在のタイルからまだタイルの置かれていない出口を通って移動すると、新しいタイルを発見する。

# 配置手順

1. タイル山の一番上を公開する。
2. 通ってきた出口と、新タイル側の入口が正しく接続する向きに置く。
3. 既存タイル、壁、通路の接続条件を満たす向きを選ぶ。
4. 新しく入った部屋やタイルに、初回進入時の処理があれば解決する。
5. タイル上に配置を指示されたトークンがあれば、所定の場所へ置く。

# 配置上の原則

- タイルは正方形のグリッドに合わせて置く。
- 通路が壁へ不正に接続する配置は避ける。
- 配置候補が複数ある場合は、ルールブックの接続制限を満たす向きから選ぶ。
- 置かれたタイルはカタコンベの一部となり、以後すべてのプレイヤーが利用する。

# ゲームへの影響

探索によって地形がその場で生成されるため、安全な帰路が保証されない。新タイルには怪物、仕掛け、ポータル、神殿、市場、アーティファクトなどが現れることがある。
