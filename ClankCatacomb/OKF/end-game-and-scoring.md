# 脱出

アーティファクトを所持して地上の脱出地点へ戻ることが、完全な生還の基本条件となる。脱出したプレイヤーは以後通常の探索手番を行わず、残っているプレイヤーに対する終了カウントを進める側になる。

# ノックアウト

ダメージで体力が尽きるとノックアウトされる。地下深くで倒れた場合と、地上に近い安全圏まで戻っていた場合とでは、救出および得点資格が異なる。アーティファクトを獲得していない場合も最終得点に重大な影響がある。

# 終了へのカウント

最初のプレイヤーが脱出または規定の形でゲームから離脱した後、終了トラック／カウントが進む。残ったプレイヤーには帰還までの猶予があるが、カウント進行に伴ってドラゴンの圧力が高まる。最終段階に達するとゲームを終了する。

# 得点

得点資格を持つプレイヤーは、以下を合計する。

- 持ち帰ったアーティファクトの勝利点。
- 獲得したカードに記載された勝利点。
- 金貨。
- 秘密、偶像、囚人、市場アイテムなどに記載された勝利点。
- 脱出や生還に関するボーナス。

合計勝利点が最も高いプレイヤーが勝者となる。同点処理は原典14ページの記載に従う。
