# 移動

ブーツを消費して、現在地から通路でつながった隣の部屋へ移動する。通路に追加条件がある場合は、その条件も満たす。

- 足跡が複数示された通路は、示された数のブーツが必要。
- モンスターの危険が示された通路では、剣で防げない分のダメージを受ける。
- 鍵など特定アイテムを要求する通路は、その条件を満たさない限り通れない。
- 一方通行の矢印がある場合は、矢印の方向にのみ移動できる。

# カードの獲得

スキルを支払い、ダンジョン列のカードを獲得する。獲得したカードは通常、即座に手札へは入らず捨て札に置かれ、後のシャッフルからデッキに加わる。カード種別やテキストに即時効果がある場合はそれを解決する。

# モンスターとの戦闘

カード列にいるモンスターへ、示された剣を支払って戦う。報酬を受け取るが、通常モンスターカードそのものはデッキに加えない。剣がある限り、同じ手番に複数回または複数の対象と戦える場合がある。

# 装置の使用

装置はカードを獲得するのではなく、必要なスキルを支払って記載された効果を即座に得る。使用後も列に残るものは、同一手番中の再利用制限などカードの指示に従う。

# アーティファクト

アーティファクトのある部屋で取得できる。原則として各プレイヤーが持ち出せるアーティファクトは1つ。取得は脱出・得点・ゲーム終了条件に関係する。

# その他の取得物

市場アイテム、大小の秘密、偶像、囚人などは、対応する部屋やアイコンに到達したときに取得・使用する。個別の意味は[部屋・通路・タイル要素](tile-features.md)と[カードとアイテム早見表](card-and-item-reference.md)を参照。
