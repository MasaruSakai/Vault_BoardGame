# 手番の基本

手番では、手札にあるカードをすべてプレイする。カードは1枚ずつ任意の順番で解決でき、得た資源や効果を使って複数のアクションを組み合わせられる。

# 主な資源

- **スキル**: ダンジョン列などから新しいカードを獲得する。
- **ブーツ**: 通路を移動する。
- **剣**: モンスターとの戦闘や、通路上の危険への対応に使う。
- **クランク！**: 指示された数の自色キューブをクランク！領域へ置く。通常は不利益である。

使わなかった資源は次の手番へ持ち越さない。

# 手番中にできること

- 通路を移動する。
- 新しいカードを獲得する。
- モンスターと戦う。
- 市場や装置を利用する。
- アーティファクトや各種トークンを獲得する。
- カードのテキスト効果を解決する。

# 手番終了

1. プレイしたカードを捨て札にする。
2. 手札が規定枚数になるまで自分の山札から引く。山札が足りなければ捨て札を混ぜて新しい山札を作る。
3. ダンジョン列の空きを補充する。
4. 補充したカードにドラゴン攻撃アイコンがあれば、補充完了後にドラゴンの攻撃を解決する。

詳細な選択肢は[基本アクション](basic-actions.md)、攻撃処理は[ドラゴンの攻撃とダメージ](dragon-attacks-and-damage.md)を参照。
