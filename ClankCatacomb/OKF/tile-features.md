# 通路

タイル間・部屋間の線が移動可能な接続を示す。足跡、モンスター、鍵、一方通行などの記号があれば、移動時に追加コストまたは制限を適用する。

# 代表的なタイル要素

- **アーティファクト**: ゲームの主要な持ち帰り対象。価値が異なる。
- **大小の秘密**: 取得時に公開し、即時効果・所持効果・得点などを得る。
- **市場**: 金貨を支払って市場アイテムを購入できる。
- **ポータル**: 対応する場所へ移動する特殊な接続。
- **神殿／特殊部屋**: 部屋固有の報酬または処理を持つ。
- **囚人**: 解放・獲得により効果や得点を得る要素。
- **猿の偶像**: 対応する部屋から運び出して得点にできるトークン。
- **ヒットポイント／ハート**: 回復またはダメージに関係する。
- **危険な通路**: 剣、追加ブーツ、鍵などを要求する。

# 初回処理と継続利用

タイルを初めて発見したときだけ起こる処理と、部屋にいる間または到達するたびに利用できる処理を区別する。トークンを取る効果は、原則としてそのトークンが残っている場合にのみ利用できる。
