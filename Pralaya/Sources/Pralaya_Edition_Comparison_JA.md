# Pralaya オリジナル版とリバイズド版の違い

調査日：2026-09-10  
対象：

- **オリジナル版**：Pralaya（2015年版）
- **リバイズド版**：Pralaya revised edition（2018年版）

## 結論

リバイズド版は、単なる再版や翻訳版ではなく、オリジナル版のルールとバランスを調整し、一部のデザインも変更した版です。公式紹介でも「前作のバランス調整」と「一部デザインの変更」が明記されています。

特に大きな変更は、次の4点です。

1. **脱出船（ドーニー）の扱い**が、島からランダムに出てくるカードを取る方式から、人数分の船を価格付きで購入する方式に変わった。
2. **プレイヤー人数に応じて場の広さ・聖典・船の枚数を調整**するようになった。
3. **脱出後のプレイヤーもゲームに残って行動**できるようになった。
4. **悪魔系カード、賢者、司祭、聖典などの得点・効果が大幅に変更**された。

## 基本仕様の比較

| 項目 | オリジナル版 | リバイズド版 |
|---|---|---|
| 発表・発売時期 | 2015年 | 2018年（ゲームマーケット2018秋で案内） |
| カード枚数 | 90枚とする商品情報が複数ある | 95枚 |
| プレイ人数 | 資料により2～5人／3～5人の表記がある | 2～5人 |
| プレイ時間 | 約20分（資料によって20～30分） | 15～30分 |
| 場の基本形 | 3列×6枚（18枚）として説明されている | 2～3人は3列×5枚、4～5人は3列×6枚 |
| ルールブック | 日本語版 | 日本語・英語のバイリンガル版 |
| 位置づけ | 初版 | ルール・バランス・一部デザインの改訂版 |

※オリジナル版のプレイ人数表記は、販売店・データベースによって揺れがあります。リバイズド版の人数別セットアップは、リバイズド版マニュアルおよび公式紹介に基づいています。

## 1. 脱出船（ドーニー）の変更

### オリジナル版

公開されているオリジナル版のプレイ解説・ルールまとめでは、船（小船／ドーニー）は次のように扱われています。

- 船カードが遺物カードの山に混ざっており、場にランダムに登場する。
- 船を取るにはアクションパワーを2使う。
- 船を取ったとき、手札の遺物を得点エリアへ移す。
- 船を保持してそのまま脱出するか、船を捨ててゲームを続けるかを選ぶ。
- 公開レビューでは、脱出には船を2回取得する必要があった旧仕様として説明されている資料もある。

つまり、オリジナル版では「船がいつ場に出るか」と「今すぐ脱出するか、さらに遺物を集めるか」が大きな不確定要素でした。

### リバイズド版

リバイズド版では、船は通常の遺物カードから分離され、プレイヤー人数に応じた枚数を用意します。船には価格があり、価格の異なる船を重ねて、安い船から順に購入します。

- 船の枚数はプレイヤー人数と同じ。
- 2人では価格 **X・7**、3人では **X・7・4**、4人では **X・7・4・2**、5人では **X・7・4・2・10** を使用。
- `X` の船は、手札のコインをすべて支払う。コインを持っていなければ無料で購入できる。
- 船を購入した時点で脱出する。旧版のように船を取った後で継続する選択はない。
- 脱出後もプレイヤーはゲームから除外されず、以降の自分のターンでは遺物を取る代わりに、場の遺物カードを1枚捨てる。

リバイズド版では、船の出現運よりも「所持金をいつ使うか」「他のプレイヤーより先に安い船を買うか」が重要になっています。公式紹介も、ドーニーの登場時期と使用条件を変更したことで、プレイヤーの選択がより重要になったと説明しています。

## 2. 人数別セットアップの追加

オリジナル版の公開ルールまとめでは、島は基本的に3列×6枚で準備されます。船も通常のカード群に含まれていたため、船が初期配置に出過ぎた場合の調整が必要でした。

リバイズド版では、最初から人数別に調整します。

- **2～3人**：3列×5枚
- **4～5人**：3列×6枚
- 聖典（Veda）は人数分を用意。
- ドーニーも人数分を用意。
- ドーニーの価格構成も人数によって変える。

この変更により、少人数で場が広すぎたり、船が不足したりする問題を抑え、人数によるプレイ感の差を小さくしています。

## 3. 脱出と得点方法の変更

### オリジナル版の考え方

オリジナル版の公開ルール解説では、手札の遺物はそのままでは最終得点にならず、船を使って得点エリアへ送り出す必要があると説明されています。島が沈む前に船で遺物を確保できれば、本人が最後まで生き残れなくても得点になる、という構造です。

そのため、旧版は次の2つを同時に判断するゲームでした。

- 自分自身が脱出できるか
- それまでに遺物を船へ積み、得点エリアへ送れるか

### リバイズド版の考え方

リバイズド版では、ドーニーを購入したプレイヤーが脱出者となり、ゲーム終了時に脱出者だけが遺物の得点計算を行います。脱出できなかったプレイヤーは得点計算の対象外となり、最低順位として扱われます。

旧版にあった「船で遺物を先に送り出しておく」という得点エリア中心の仕組みや、船を保持して脱出すると得られる生存ボーナスは、リバイズド版のマニュアルでは採用されていません。代わりに、脱出後も場のカードを減らす行動を続けるため、脱出のタイミングが他プレイヤーへの圧力になります。

## 4. カード効果の主な変更

オリジナル版のカード効果は、公開されているプレイ解説・カード一覧を基準に整理しています。オリジナル版の公式マニュアル全文をウェブ上で確認できなかったため、以下の旧版欄は「公開二次資料による整理」です。

| カード／要素 | オリジナル版 | リバイズド版 |
|---|---|---|
| 悪魔の像（Demon Statue） | 枚数に応じた大きなマイナス／プラス得点。公開資料では1枚=-10、2枚=-20、3枚=+40と説明 | 1枚につき2点。悪魔の取引との組み合わせで倍率が変わる |
| 悪魔の取引（Demonic Pact） | 特殊カード。-3点だが、そのターンのアクションパワーを増やす | 通常の遺物カード。悪魔の像の得点倍率を、1枚=-3倍、2枚=9倍、3枚=-27倍、4枚=81倍にする |
| 賢者（Pundit） | 特殊カードとして写本を得点エリアへ移し、写本の得点を倍化 | 持っている異なるカード種類の数を得点にする遺物カード |
| 司祭（Brahmin） | 得点時に聖典を得たり、悪魔の像・悪魔の取引を含むカードを除去したりする効果として説明 | 悪魔の像を0点にし、聖典を15点として扱う |
| 聖典（Veda） | 公開資料ではコイン7枚で購入し、アクションパワーを増やし、船を持つ場合のボーナスを与える | コインで購入し、以後のアクションパワーを3から4へ増やす。リバイズド版では価格と得点効果が変更 |
| 船／ドーニー | 遺物デッキ内のランダムな船。取得後に継続か脱出かを選ぶ | 専用の船カード。価格順に購入し、購入時に即脱出 |

最大の変更は、悪魔の像を単独で集めるだけではなく、悪魔の取引との枚数を組み合わせて得点を狙う仕組みになったことです。これにより、旧版の単純な枚数依存の危険札から、リバイズド版では大きなプラス／マイナスが発生する組み合わせ札へ変わっています。

## 5. コンポーネントと読みやすさ

オリジナル版の商品情報は90枚、リバイズド版の公式情報は95枚としています。リバイズド版はカード枚数が5枚増えており、人数別の船・聖典やカード効果の再設計に対応しています。

また、リバイズド版はアートワークを維持しつつ、フォントを大きくして読みやすくしたと紹介されています。ルールを確認しながら遊ぶ場合の視認性は、リバイズド版の方が高いと考えられます。

## 版を混ぜて遊べるか

基本的には、**オリジナル版とリバイズド版のカードやルールを混ぜない方が安全**です。特に次の部分が互換ではありません。

- 船が通常デッキに入るか、専用の価格付きデッキになるか
- 脱出条件と脱出後の行動
- 手札・得点エリアの扱い
- 悪魔の像、悪魔の取引、賢者、司祭、聖典の効果
- 人数別の場の枚数

旧版のカードを使いたい場合は旧版ルール、リバイズド版のカードを使う場合はリバイズド版ルールを一式で使用するのがおすすめです。

## 調査上の注意

- リバイズド版の発売時期、仕様、改訂意図は、ゲームマーケットの公式紹介とDomina Gamesの製品ページで確認できます。
- オリジナル版は、公式の初回告知で2015年の作品であることと基本テーマを確認し、細かなカード効果は公開されているプレイ解説・ルールまとめで補いました。
- オリジナル版の販売情報は「90枚」としていますが、公開されているカード内訳の一部には合計が一致しないものがあります。そのため、旧版の個別カード枚数は断定せず、確実性の高いルール差を中心に整理しています。
- オリジナル版のプレイ人数も、資料により2～5人と3～5人の表記が混在しています。
