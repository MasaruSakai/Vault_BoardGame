# Pralaya オリジナル版とリバイズド版の比較

## Summary

リバイズド版は、オリジナル版の再印刷ではなく、ルールとバランスを調整し、一部デザインを変更した版です。最も大きな変更は脱出船の仕組みです。

| 論点 | オリジナル版 | リバイズド版 |
|---|---|---|
| 発売時期 | 2015年 | 2018年 |
| カード総数 | 90枚とする商品情報 | 95枚 |
| 島の初期配置 | 公開旧版資料では3×6 | 2～3人は3×5、4～5人は3×6 |
| 船 | 遺物デッキに混ざるランダムな船として説明 | 人数分の専用ドーニーを価格順に購入 |
| 脱出 | 船の取得・保持・継続の判断が中心 | ドーニー購入時に即脱出 |
| 脱出後 | 公開旧版資料では、船に遺物を送り出してから脱出する構造 | 島の遺物を1枚捨てる行動を継続 |
| 得点 | 得点エリアへ送った遺物を中心に計算する旧版構造 | 脱出者が手札の遺物を計算。未脱出者は最下位 |
| カード効果 | 悪魔系・賢者・司祭・聖典などは旧効果 | それぞれ得点・購入・行動効果を再設計 |

## Major differences

### 1. Dhoni changes from random availability to a price race

オリジナル版では、公開されている旧版解説に基づくと、船が遺物カード群に混ざって場に現れます。船を取るタイミングが不確実で、取得後にさらに遺物を集めるか脱出するかを判断します。

リバイズド版ではドーニーを遺物デッキから分離し、人数分の価格付きカードを用意します。価格X、7、4、2、10の採用範囲は人数で変わり、購入した時点で脱出します。これは「船が見えるまで待つ」ゲームから、「コインをいつ使って何番目に脱出するか」を競うゲームへの変更です。

### 2. Escaped players remain active

リバイズド版では、脱出済みプレイヤーもゲームから除外されません。以降の自分の手番では、遺物の獲得の代わりに島の遺物を1枚捨てます。脱出が単なる安全確保ではなく、島を沈めるタイミングを操作する行為になっています。

### 3. Scoring is consolidated around the escaped hand

オリジナル版は、公開旧版資料では手札の遺物を船で得点エリアへ送る仕組みが中心です。リバイズド版は、脱出者の手札にある遺物をゲーム終了時にまとめて計算します。未脱出者は得点計算を行いません。

### 4. Card effects are redesigned

- 悪魔の像：旧版の枚数依存の大きなマイナス／プラスから、リバイズド版では1枚2点＋悪魔の契約との倍率計算へ。
- 悪魔の契約：旧版の特殊な行動力補助・減点カードから、悪魔の像の得点倍率を変える遺物カードへ。
- 賢者：旧版の写本倍化から、持っているカード種類数を得点するカードへ。
- 司祭：旧版の聖典取得・カード除去系の効果から、悪魔の像を0点にし、聖典を15点にする効果へ。
- 聖典：旧版の固定価格・船とのボーナスを含む構造から、コインで購入して行動力を4にする構造へ。

## Compatibility

両版は、船・得点エリア・脱出後の行動・カード効果・人数別セットアップが異なるため、ルールとカードを混ぜず、それぞれの版で一式使用するのが安全です。

## Evidence level

- リバイズド版のルールは、[Sourcesの日本語マニュアル](../../Sources/Pralaya_Rulebook_JA.md)、[英語マニュアル](../../Sources/Pralaya_Rulebook_EN.md)、[PDF](../../Sources/rule201811.pdf)を基準に整理。
- リバイズド版が単なる再版でないこと、2018年版の仕様、人数別調整は公式告知で確認。
- オリジナル版の細かなカード効果・船の挙動は、公式旧版マニュアル全文ではなく公開二次資料に基づく。旧版のカード内訳には合計が合わない公開リストもあるため、個別枚数は断定しない。
