# Pralaya ゲーム概要

## Theme and objective

悪魔によって沈み始めた島から遺物を集め、脱出するゲームです。リバイズド版では、ゲーム終了時にドーニーを持っているプレイヤーだけが手札の遺物を得点計算します。脱出していないプレイヤーは得点計算を行わず、最下位になります。

## Core loop

1. 島に並んだ遺物カードから、行動力を使って1枚以上を手札に加える。
2. コインを支払って、聖典またはドーニーを購入する。1ターンに購入できるのはどちらか一方だけ。
3. 空いた島の場所に山札からカードを補充する。
4. 海が増え、選べる遺物が減る前に脱出するか、さらに高得点の遺物を狙う。

## Main decisions

- 銅貨・銀貨・金貨を、得点として残すか、聖典／ドーニーの購入資金にするか。
- 行動力を安価なカードに分割して使うか、高コストカードに集中するか。
- 早くドーニーを買って脱出を確定するか、遺物を集めて得点を伸ばすか。
- 脱出後は遺物を獲得できないため、場のカードをどの順番で捨てて島を沈めるか。

## Shared vocabulary

| Term | Meaning |
|---|---|
| 遺物カード / Relic card | 島から行動力で獲得するカード。通常は手札に置く |
| 海 / Ocean | 獲得できず、島の空き場所を埋めるカード |
| 聖典 / Veda | 購入すると、脱出までの行動力を増やすカード |
| ドーニー / Dhoni | 購入したプレイヤーを脱出者にする船カード |
| 行動力 / Vitality | 遺物を獲得するために使う、そのターンの資源 |
