# BoardGameGeek フォーラム資料

テラフォーミング・マーズの英語フォーラムを、Rules（ルール裁定）と Strategy（戦略議論）に分けて整理した資料群。各トピックは、質問の背景、スレッドで共有された結論、実戦上の含意を日本語で要約している。

## 使い分け

- [Rules フォーラム索引](bgg-rules/index.md)：ルールの読み方・処理順・カードやタイルの裁定。最終判断は日本語マニュアルまたは公式FAQを優先する。
- [Strategy フォーラム索引](bgg-strategy/index.md)：基本ゲームを中心とした戦略・カード評価・ソロ攻略。環境、人数、ドラフト、拡張の有無で結論が変わるため、定説ではなく議論の整理として読む。

## 編集方針

フォーラム全件を本文転載するのではなく、Rules では再利用性の高い裁定、Strategy ではプレイ方針の比較に役立つトピックを選んで、1トピック1ファイルにした。個別カードの細かな裁定や、拡張固有の話題は今後必要になった時点で追加できるよう、原典URLとスレッドIDをファイル名に含めている。

取得時点のフォーラム表示では Rules は約1,533件、Strategy は約236件のトピックがあり、本資料はそのうちの代表的なトピックを収録している。
