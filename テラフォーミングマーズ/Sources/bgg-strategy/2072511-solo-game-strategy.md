# Solo Game Strategy

## 質問

基本ソロを何度か遊んでも14世代以内にテラフォーミングできず、カード購入で資金が消え、エンジンが動き始める第7〜10世代には残り時間が足りない、という相談。

## スレッドの回答から得られる要点

### 1. ソロ初期盤面を忘れない

基本ソロでは、通常の対戦相手の代わりに中立の都市・緑地が置かれる。これらは都市隣接や緑地配置の起点になるため、盤面の空きだけを見て戦略を立てない。都市・緑地を活用できるカードや配置を先に確認する。

### 2. 勝利条件と高得点を分ける

勝つためには14世代以内に3つのグローバルパラメータを完成させることが最優先。Jovianタグや純VP、長期の動物・微生物カードは、テラフォーミングに直接寄与しない限り、最初の判断では切る。高得点を狙うプレイは、勝利が安定してから行う。

### 3. 早期に収入を作る

カード購入費が重いので、最初から大量のカードを保持しない。少数の強い生産・割引カードを置き、カードを買わずに標準プロジェクトを使う世代も許容する。特に、残り世代で回収できない純粋な生産投資は避ける。

### 4. テラフォーミングを分散する

植物だけ、温度だけに依存すると、カードの引き運で詰まりやすい。植物・熱・電力、直接TR、海洋・酸素・温度を組み合わせ、どのトラックも14世代の終盤までに完成するようにする。

## 結論

基本ソロは「良いカードを引いて最高点を出す」より、「勝利に不要なカードを切り、毎世代テラフォーミングへ変換する」パズルとして見ると安定する。標準プロジェクトは高価でも、カード待ちで1世代を失うより有効なことがある。
