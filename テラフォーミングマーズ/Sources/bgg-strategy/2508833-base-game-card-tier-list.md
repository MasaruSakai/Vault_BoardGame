# Base Game Card Tier List Attempt

## 主題

基本ゲームのプロジェクトカードをTier表に分類し、強いカード・状況依存のカード・初心者が扱いにくいカードを整理する試み。

## Tier表を読むときの軸

- **早期生産・割引**：第1〜5世代に引けば、残りのカードや標準プロジェクトの回数を増やす。
- **直接テラフォーミング**：TR、温度、酸素、海洋を押し、終了速度を変える。終盤でも価値が残る。
- **カードドロー**：選択肢を増やすが、購入費と手札の死蔵を伴う。
- **盤面カード**：都市、緑地、海洋隣接、配置ボーナスを組み合わせたとき強い。
- **純VP／長期資源**：残り世代と要件がそろわないと回収できない。

## スレッドの合意点

カードのTierはカードそのものの順位ではなく、引いた世代、企業、人数、マップ、ドラフト、他カードとのシナジーを含む条件付きの評価である。たとえば、一般に弱いとされるカードも、要件をすでに満たしている、相手の勝ち筋を止める、特定の生産・タグが大量にある、という場合は上位に移る。

## 使い方

Tier表を暗記するより、カードを取るときに「いつプレイするか」「何回回収するか」「出さない場合の代替行動は何か」を説明する。ドラフトでは自分の評価と相手に渡した場合の強さの差を考える。
