# Base Game + Prelude - General Strategy guideline

## Prelude込みで変わること

Prelude はゲーム開始時から生産、資源、カード、TRを与えるため、基本ゲームより序盤の立ち上がりが速い。最初から長い生産エンジンを組むより、Prelude で得た方向性をプロジェクトカードへ接続し、テラフォーミングと得点へ早く変換することが重要になる。

## ガイドの整理

- Prelude の生産と初期カードを、最初の数世代で回収できるか確認する。
- Prelude のタグや資源に合うカードを無理に探し続けず、直接TR・温度・酸素・海洋へ進めるカードも残す。
- Prelude でカードや資金を得ても、手札を膨らませるだけなら意味がない。カードドローの購入費を含める。
- 早期のマイルストーンや盤面ボーナスが取りやすくなるため、相手が狙う場所を早めに確認する。
- Prelude でゲームが加速する分、終盤の純VPカード・遅い生産・長期コンボは基本ゲームより回収しにくい。

## まとめ

Prelude は「序盤を省略する拡張」ではなく、最初から各企業の方向性を強め、ゲームのテンポを上げる拡張。Prelude カード2枚と初期手札を別々に評価せず、初期数世代でどのトラックを何段階押せるかで判断する。
