# How to end the game earlier?

## 質問

カードドローと科学エンジンを大きくして終盤にカードを一気に出す戦略に対し、植物・温度・海洋を押して第11〜12世代程度で終えるにはどうすればよいか、という相談。

## スレッドの要点

### 1. ゲーム速度は人数と相手の方針で変わる

2人戦で両者がカードを大量に出すと世代数が伸びる。3人戦でも複数人が大きなエンジンに入ると、テラフォーミングだけを急ぐプレイヤーは相対的に不利になりやすい。まず「早く終える」ことを目的にするより、相手が何世代を必要としているかを読む。

### 2. 早期終了型の入口

初期手札から、植物生産、熱生産、海洋・温度・酸素を直接上げるカード、青カードの毎世代テラフォーミング効果を探す。カードで押せない場合でも、標準プロジェクトが、何もしないアクションよりTRと終了進行を生むことがある。

### 3. 経済とテラフォーミングを分離しすぎない

生産エンジンを最大化してから最後にテラフォーミングするのではなく、序盤の収入カードを数枚置いたあと、TRを上げるカードと標準プロジェクトへ移る。終了を早めると相手の後半のカードドロー・VPカードの回収機会も減る。

### 4. 盤面で得点を回収する

植物型なら緑地を先に増やし、都市を必要な場所へ置いて都市隣接VPと賞・マイルストーンを同時に取りに行く。早く終えるだけでなく、終了時点で自分の盤面が得点に変換されていることが必要。

## 結論

テラフォーミング型は、固定の「急ぐデッキ」ではない。よい生産・割引・カード効果を引いたときにそれを早いTRへ変換し、相手が大量のカードを回収する前に終了させる、というテンポ選択である。
