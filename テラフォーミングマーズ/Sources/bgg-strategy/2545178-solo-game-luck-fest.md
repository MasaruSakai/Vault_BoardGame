# Is the solo game a luck fest?

## 論点

ソロで14世代以内に必要なカードが引けないゲームがあり、勝敗がカード運だけで決まるのではないか、という議論。

## 運が大きく見える理由

- 対戦相手がいないので、必要なタグ・生産・テラフォーミング効果を自分だけで引く必要がある。
- ソロは世代数が固定され、序盤の1〜2世代の遅れが後で取り戻しにくい。
- 直接テラフォーミングカードを待つと、カードドローの投資も含めてテンポを失う。

## 意思決定で下げられる運

スレッドでは、勝利だけを目的にするなら、純VP・長期のJovian・高価なコンボを切り、標準プロジェクト、植物・熱・電力の変換、安価な生産カードを活用する意見が出ている。標準プロジェクトはカード運を完全には消さないが、最後の不足を埋める確実な出口になる。

また、最初から高得点を追わず、ソロに向く企業と初期手札を選び、2〜3世代で引き直すようにカードを厳選することで、不要な購入を減らせる。拡張を入れると直接TRやPreludeで運の分散が変わるため、基本ソロの難度と同じに扱わない。

## 結論

ソロには確かにカード運があるが、運だけのゲームとするより、14世代という制約の下で「何を捨て、いつ標準プロジェクトへ切り替えるか」を問うゲームと捉える方が近い。負け手を高得点用の手札で試すのではなく、勝利条件への最短経路で評価する。
