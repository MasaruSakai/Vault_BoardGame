# BGG Rules トピック索引

## 利用順

1. まず[日本語マニュアル](../TM_RULEBOOK_JPN-reprint2018w.pdf)とカード本文を確認する。
2. 疑問の形が近い行を選び、個別ファイルの「質問」「結論」「処理例」を読む。
3. Wiki側で他の概念との関係を確認する場合は、[ルールFAQ・17問のQ&A](../../Wiki/faq/rules-faq.md)を読む。
4. BGGの回答が版・拡張・ソロに依存する場合は、その前提を崩して基本ゲームへ一般化しない。
