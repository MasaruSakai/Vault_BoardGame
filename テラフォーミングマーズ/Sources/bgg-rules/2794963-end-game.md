# End game

## 質問

3つのグローバルパラメータがすべて目標に達したあと、ただちに得点計算へ移るのか、それともその世代を最後まで行うのか、という確認。

## スレッドの結論

ゲーム終了条件を満たした世代でも、通常どおりその世代の残りのアクションを行う。世代終了後に生産フェイズまで解決し、その後、各プレイヤーは手持ちの植物を緑地タイルへ変換する最後の機会を、手番順に1回ずつ得る。そこで置いたタイルは通常の配置として扱われ、配置ボーナスなども処理する。その後に最終得点を計算する。

つまり「最後のパラメータを上げたアクションの直後に中断」ではない。終了条件は、その世代を終了させるフラグである。

## 日本語マニュアルとの対応

- 3つのグローバルパラメータ達成後も、現在の世代を終了する。
- その世代の生産を行う。
- 生産後、植物を緑地へ変換できる最後の機会がある。
- 最後の緑地配置が酸素や配置ボーナスを動かす可能性がある。

## 注意

ソロゲームの「14世代以内にテラフォーミングを完了する」という勝敗判定とは混同しない。マルチプレイの終了処理と、ソロの勝敗判定・最終得点での植物変換は、同じ「最後の緑地配置」が登場しても意味が異なる。
