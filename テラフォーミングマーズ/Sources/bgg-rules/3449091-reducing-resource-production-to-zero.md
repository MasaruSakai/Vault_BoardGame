# Reducing Resource Production to 0

## 論点

相手や自分の資源生産を減らすカード効果で、現在の生産量より大きな減少を指定できるのか。生産量を0未満にできるのか、という確認。

## 結論

通常の資源（鉄、チタン、植物、電力、熱）の生産量は0を下限とする。減少効果は生産量を0まで下げるところで止まり、存在しない生産をさらにマイナスにはしない。M€生産だけは、基本ルールで定められた下限まで負になることがあるため、M€生産と他資源の生産を同じ扱いにしない。

カードに「最大」「少なくとも」「可能な限り」などの語がある場合は、その指定範囲を確認する。複数の資源から選べる効果なら、減らす資源の種類をカードの条件内で選ぶ。指定された資源を0にしても残りの減少分を別資源へ自動的に移すことはできない。

## 処理例

鉄生産が2のプレイヤーに「鉄生産を3下げる」効果を適用する場合、鉄生産は0になる。鉄生産が0になった後に、余った1をM€生産や別の資源へ勝手に振り替えない。

## 実戦上の注意

生産を0に下げる効果は、相手の次の生産フェイズを止めるだけで、すでに持っている資源を取り除く効果ではない。「生産を減らす」と「資源を失う／捨てる」は別の処理として読む。
