# Tiles placed on other tiles?

## 質問

Lava Flows のような特殊タイルで、既存の都市・緑地・特殊タイルを置き換えられるか。また、緑地や都市を既存タイルの上に置けるか、という基本配置の確認。

## 結論

Terraforming Mars のタイルは、原則として空いている合法なスペースに置く。すでにタイルがあるスペースは使用済みなので、新しいタイルを重ねたり、既存タイルを取り除いて置き換えたりできない。

これは「そのカードがタイルを置く」と書いてある場合でも同じ。カードに特別な上書き・除去処理が明記されていない限り、既存タイルのある場所は候補から外す。

## プレイ時の確認順

1. そのスペースが海洋予約地・都市予約地などの専用スペースでないか確認する。
2. 既にタイルが置かれていないか確認する。
3. カード固有の隣接条件・配置制限を確認する。
4. 配置後に所有マーカー、配置ボーナス、海洋隣接ボーナスを処理する。

## 注意

「タイルを置く」と「タイルを除去する」は別の効果である。既存タイルを動かせるように見えるカードや拡張要素については、そのカード固有の文言を優先し、通常のタイル配置ルールから一般化しない。
