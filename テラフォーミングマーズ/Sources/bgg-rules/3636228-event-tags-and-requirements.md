# Does tags in event count for requisites?

## 質問

イベントカードはプレイ後に裏向きになるが、上部のタグを、後続カードの要件や賞・マイルストーンの集計に使えるのか、という確認。

## スレッドの結論

イベントタグは、そのイベントカードをプレイしているアクション中は有効で、同じアクション中に誘発する効果を処理できる。しかし、解決後に裏向きのイベント置き場へ移ったタグは「場に出ているタグ」として残らない。後続カードのタグ要件、Scientist などの集計、通常のタグ参照の賞には、原則として数えない。

したがって、科学タグ付きイベントをプレイした瞬間に Mars University や Olympus Conference のような「カードをプレイしたとき」の効果を誘発することはあるが、その科学タグを使って後から別の科学要件カードをプレイすることはできない。

## 参照対象を分ける

- 「イベントをプレイした枚数」：イベント置き場の裏向きカードを数える。
- 「タグを持つカード」：イベントは、プレイ中の誘発を除き、場のタグ集計には数えない。
- 「場の青カード／緑カード」：イベントは別のカード種別なので、含めないことが多い。
- 「カード本文の効果」：イベントの即時効果は解決済みで、後から再発動しない。

日本語マニュアルの「イベントは裏向きに置く」という物理的処理と、「プレイ中だけタグが働く」というゲーム上の情報を混同しない。カードが「イベントカードの枚数」「このカードをプレイしたとき」「場にある特定タグ」のどれを指定しているかで判定する。イベント枚数を明示的に数えるカードなど、例外的にイベントを参照する効果はカード本文を優先する。
