# Counting face-down red Event cards' tags?

## 質問

裏向きにした赤いイベントカードのタグを、ゲーム中や終了時の要件・VP・賞の判定に数えるのか、という確認。

## 結論

イベントタグはカードをプレイしているアクション中だけ働く。たとえば、イベントに科学タグがあれば、プレイ時に Mars University や Olympus Conference のような「カードをプレイしたとき」の効果を誘発できる。しかし、イベントを裏向きに置いた後、その科学タグを後続カードの要件、Scientist、タグごとのVP、通常の賞へ使うことはできない。

イベントそのものの枚数を数える効果や、イベントカードをプレイした事実を指定する効果は別。これは「イベントタグが場に残る」こととは違う。

## プレイ時の判定

1. イベントをプレイし、カード本文の即時効果を解決する。
2. 同じアクション中に、タグを条件とする誘発効果を処理する。
3. 効果解決後、イベントを裏向きのイベント置き場へ置く。
4. 以後の通常のタグ集計からは外す。ただし、イベントの枚数・イベント置き場・カード固有の明示的参照は残る。

## まとめ

イベントタグは「一時的な誘発タグ」であって、「場に出ているタグ」ではない。イベントカードを根拠に要件を満たしたいときは、後続カードのプレイ前に同じアクション内で処理できる効果なのかを確認する。
