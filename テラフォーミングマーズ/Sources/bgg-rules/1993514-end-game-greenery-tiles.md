# End Game Greenery Tiles

## 質問

最終生産で植物が21個ある場合、植物8個ごとの緑地配置を、他プレイヤーの間に割り込まれる形で1枚ずつ行うのか、それとも自分の最後の機会に3枚とも続けて置けるのか、という質問。

## スレッドの結論

最後の植物変換は、通常の世代中のアクションを再開するものではない。各プレイヤーが手番順に自分の植物を変換する「最後の機会」なので、21植物なら同じプレイヤーが最大3枚を連続して配置できる。8植物ごとに緑地を1枚置き、残りが5植物になる。

各緑地は通常の緑地配置として処理する。そのため、空いている合法な場所、所有タイルへの隣接、配置ボーナス、海洋隣接によるM€、酸素トラックの上限など、通常の制約と効果は残る。

## 実戦上の含意

- 先手の最終緑地配置で、複数の良い場所をまとめて確保できる。
- 配置ボーナスでさらに植物を得る場合、同じ最後の機会の中で追加の緑地を置ける可能性がある。
- 都市への隣接得点は、都市の所有者に関係なく、最終盤の緑地配置でも発生する。
- 他プレイヤーの植物変換を待ってから自分の場所を決める、という交互アクションではない。

## 注意

「最後の機会」は、通常アクションの回数を増やすルールではない。通常の植物変換アクションを複数回行う場合と、最終処理の一括的な機会を区別すること。
