# アイコンとタグ

アイコンの意味がカード本文と食い違って見える場合は、まずカード上の文章を読む。アスタリスク（*）付きのアイコンには、そのカード固有の特殊ルールがある。

## パラメータ

| 表示 | 意味 |
| --- | --- |
| TR | 地球化指数。ゲーム終了時1TR=1VP、産出フェイズのM€収入にも加算 |
| 気温 | -30℃から+8℃まで、1段階2℃。上昇時に自分のTR+1 |
| 酸素濃度 | 0%から14%まで。上昇時に自分のTR+1 |
| 海洋タイル | 海洋タイル1枚を配置し、自分のTR+1。配置ボーナスを得る場合がある |

## 資源

| 資源 | 意味と主な処理 |
| --- | --- |
| M€ | 通貨。カード購入・プレイ、標準プロジェクト、称号、褒賞などに使う |
| 建材 | 建物タグのカードの支払いに使い、1個2M€として扱う |
| チタン | 宇宙タグのカードの支払いに使い、1個3M€として扱う |
| 植物 | 8個を緑地タイル1枚に変換し、酸素濃度とTRを1段階上げる |
| 電力 | 青いアクションや産出量減少で消費。産出フェイズ開始時に余剰分を発熱へ移す |
| 発熱 | 8個を消費して気温とTRを1段階上げる |
| 特殊資源 | 動物や微生物など。対応するカード上に置く |

## タグ

カード右上には、0～3個の異なるタグがある。タグを持つカードをプレイしたとき、そのカードのタグ自体もプレイされたものとして扱う。

| タグ | 分野 |
| --- | --- |
| 建物 | 火星での建設。建材を支払いに使える |
| 宇宙 | 宇宙技術。チタンを支払いに使える |
| 電力 | 電力を扱う、または生み出すプロジェクト |
| 科学 | 科学知識。科学タグ数を条件にするカードもある |
| 木星 | 外太陽系のインフラ |
| 地球 | 地球での活動 |
| 植物 | 植物や光合成生命体 |
| 微生物 | 微生物や小型無脊椎動物 |
| 動物 | 比較的大きな脊椎動物。VPを生むことがある |
| 都市 | 都市を設置するプロジェクト。電力産出量を条件にすることが多い |
| イベント | 使い切り。すべて赤いカードで、プレイ後は裏向き |

カードを1枚手札に加えるカード・アイコンのボーナスを得た場合、プロジェクトの山から1枚引き、購入コストなしで手札に加える。

## タイル・アイコン

- 海洋アイコンは海洋予定地への海洋タイル配置。
- 緑地アイコンは緑地タイルと自分のプレイヤー・マーカーを配置し、通常は酸素濃度とTRも上げる。
- 都市アイコンは都市タイルと自分のプレイヤー・マーカーを配置する。都市は他の都市に隣接させない。
- 茶色地のアイコンはカード指定の特殊タイルと所有者マーカーを配置する。

## 赤フチ

- 赤フチのアイコンは、対象プレイヤーを自分またはライバルから選べる。
- 赤フチの資源除去は1人だけに適用し、一部または全部を適用しなくてもよい。
- 赤フチの資源産出量減少は必ず適用する。減らせるプレイヤーが自分だけなら自分に適用する。
- 赤フチのタイルは、いずれか1人または全プレイヤーのタイルを対象にする。
- 赤フチのタグは、そのタグを持つ全プレイヤーのカードを対象にする。
