# 称号と褒賞

## 称号

条件を満たしたプレイヤーは、アクションとして8M€を支払い、その称号マスに自分のプレイヤー・マーカーを置く。各称号は1人だけが獲得でき、5つのうちゲーム全体で最大3つまで。早い者勝ちで、獲得した称号1つにつき終了時5VP。

| 称号 | 獲得条件 |
| --- | --- |
| 造星者 | TRが35以上 |
| 総督 | 都市タイルを3枚以上所有 |
| 緑化匠 | 緑地タイルを3枚以上所有 |
| 建設師 | 建物タグを8つ以上持つ |
| 創案主 | 手札が16枚以上 |

## 褒賞

まだ設立されていない褒賞を、アクションとして設立できる。投資額は、そのゲームで1番目が8M€、2番目が14M€、3番目が20M€。褒賞は5つのうち最大3つまでで、各褒賞は1人しか設立できない。

終了時には、設立者ではなく条件の順位を確認する。首位は5VP、次席は2VP。2人プレイでは次席VPはない。首位や次席が同数なら該当者全員がその順位のVPを得るが、首位が同数の場合、他のプレイヤーは次席VPを得られない。

| 褒賞 | 順位を比べる対象 |
| --- | --- |
| 開拓王 | 地図上で所有するタイルの数 |
| 銀行王 | M€産出量（TRは含めない） |
| 科学王 | 科学タグの数（イベントは含めない） |
| 温熱王 | 発熱資源の数 |
| 採掘王 | 建材とチタンの合計資源数 |

称号・褒賞は[バリエーション](variants.md)の1人プレイでは使用しない。
