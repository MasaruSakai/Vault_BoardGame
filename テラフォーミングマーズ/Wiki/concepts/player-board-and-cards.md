# プレイヤーボードとカード

## プレイヤーボード

各プレイヤーは、次の6種類の一般資源を自分のボードで管理する。

| 資源 | 主な用途 |
| --- | --- |
| M€ | カード、標準プロジェクト、称号、褒賞などの支払い |
| 建材 | 建物タグのカードの支払い。1個2M€として使用可能 |
| チタン | 宇宙タグのカードの支払い。1個3M€として使用可能 |
| 植物 | 8個を緑地タイル1枚へ変換 |
| 電力 | カードや都市・産業の効果で消費。余剰分は発熱へ変換 |
| 発熱 | 8個を気温1段階の上昇へ変換 |

資源ボックス内のキューブは保有資源、茶色の産出表上のマーカーは各世代に得る量を表す。産出量は10を超えてよく、10の欄にマーカーを残したまま追加のマーカーで十の位を表す。M€産出量だけはマイナスになり得るが、下限は-5。M€の実際の収入にはTRも加算されるため、収入そのものがマイナスになることはない。

産出フェイズでは、M€を「TR + M€産出量」だけ、その他の資源を表示された産出量だけ受け取る。カード上の特殊資源は、そのカード上に置く。

## 企業カード

企業カードは横向きで自分の前に置く。開始時のM€、資源、産出量、場合によっては最初のアクションが指定される。企業カードのタグと効果は、開始時に企業を公開して処理するときから有効になる。

## プロジェクトカードの種類

プロジェクトカードは、枠の色で次の3種類に分かれる。

| 種類 | 枠 | プレイ後の扱い |
| --- | --- | --- |
| イベント | 赤 | 裏向きにしてイベントの山へ置く。タグはプレイ時だけ参照 |
| オートマチック | 緑 | 表向きのまま重ねる。上のカードのタグを見えるようにする |
| アクティブ | 青 | 表向きで保持し、継続効果や世代ごとのアクションを使う |

オートマチックカードは、それまでのカード自体の効果を再適用しないが、積み重ね上部に見えるタグは現在の進捗として有効。アクティブカードは効果やアクションが使えるため、上部を隠さない。

## カードの読み方

1. タグ：他のカードやプレイヤーボードとの組み合わせで参照する分類。
2. 開始条件：企業カードに記載された開始時の資金、資源、産出量など。
3. 効果／アクション：青いタイトル枠の継続効果、またはゲーム中に使うアクション。青いアクションは各世代1回。
4. フレーバー・テキスト：背景情報で、ルール効果ではない。
5. プレイコスト：手札からプレイする際に支払うM€。カードを手札にする購入コストは別に、通常1枚3M€。
6. プレイ条件：パラメータ、タグ、産出量などの条件。プレイ時に条件を満たす必要がある。
7. 即時効果：カードをプレイしたときに直ちに解決する効果。
8. VP：ゲーム終了時に得る勝利点。プレイ中は通常無視する。
9. 管理番号：カード固有番号。ゲーム上の効果はない。

カードには、特定のタグを持つカードのプレイコストを下げる効果、資源や産出量を増減する効果、タイルを置く効果などもある。アイコンだけで処理が明確でない場合や、アスタリスク（*）が付く場合は、必ずカード本文を読む。
