# 内容物

## 一覧

| 部品 | 数量 | 用途 |
| --- | ---: | --- |
| ルール説明書 | 1冊 | ルールの原典 |
| ゲーム盤 | 1枚 | グローバル・パラメータ、TR、世代、火星地図、標準プロジェクト、称号・褒賞を管理 |
| プレイヤーボード | 5枚 | 各プレイヤーの資源と産出量を管理 |
| 企業カード | 17枚 | 各プレイヤーが担当する企業と開始時の効果を表す |
| プロジェクト・カード | 208枚 | 手札からプレイするプロジェクト |
| 早見表カード | 8枚 | ルールやアイコンの参照 |
| プレイヤー・マーカー | 200個 | 5色の半透明キューブ。TR、タイル所有権、産出量、青いアクションの使用を表示 |
| 資源キューブ | 200個 | 金属色とサイズで価値を表す。各種資源に共通して使用 |
| 海洋タイル | 9枚 | 海洋予定地に置く |
| 緑地／都市タイル | 60枚 | 緑地タイルまたは都市タイルとして使用 |
| 特殊タイル | 11枚 | カードの指示により配置 |
| 親マーカー | 1個 | 現在の親を示し、世代ごとに左隣へ渡す |
| 気温・酸素濃度・世代マーカー | 各1個 | ゲーム盤上の各トラックを表示 |

## 資源キューブの価値

資源キューブは置かれた場所によって資源の種類が決まる。サイズと色は価値だけを表し、同じ資源ボックス内では次の価値として扱う。

| キューブ | 価値 |
| --- | ---: |
| 銅 | 1 |
| 銀 | 5 |
| 金 | 10 |

資源キューブはプレイヤーボード、または動物・微生物などを生み出す特定のカード上に置く。プレイヤー・マーカー、資源キューブ、残りのタイルにはゲーム上の個数制限がなく、足りない場合は別の物で代用する。

各部品の詳しい処理は、[ゲーム盤](game-board.md)、[タイルとマーカー](tiles-and-markers.md)、[プレイヤーボードとカード](player-board-and-cards.md)を参照。
