# 早見表

## 神話トークン

| 効果 | 処理 |
|---|---|
| 破滅の拡大 | イベントカードの山の一番下から1枚引いて表向きに捨て、破滅アイコンのマスに破滅トークンを1個置く。 |
| モンスターの出現 | モンスターカードの山の一番下から1枚引き、裏面の条件に合うマスに置く。 |
| トップニュースを読む | トップニュースカードの山の一番上を1枚引き、効果を適用する。指定がなければ手番プレイヤーだけに適用する。 |
| クルートークンの出現 | イベントカードの山の一番上の裏面を確認し、描かれた区域の中央エリアにクルートークンを1個置く。その区域遭遇カード2枚とイベントカード1枚を混ぜて山の上へ戻す。 |
| 空間断裂 | イベントカードの山の一番上の裏面の区域タイル全マスに破滅トークンを1個ずつ置き、そのカードと捨て札をシャッフルして山の底へ入れる。 |
| 同時発生効果 | シナリオシートに記されたすべての同時発生効果を適用する。 |
| 何も起きない | 効果なし。 |

## 遭遇アイコン

| アイコンの意味 | 処理 |
|---|---|
| 知識／影響力／観察力／筋力／意志力 | 対応するスキルの能力判定を行う。 |
| お金を消費 | 指定されたお金トークンを支払う。 |
| 体力／正気度を回復 | 対応するトークンを指定点数取り除く。 |
| 一般のアイテム／古のアイテム | 対応する種別のアイテムカードを得る。 |
| 呪文 | 呪文カードを得る。 |
| お金／遺物を得る | 対応するトークンを得る。 |

## イベントカード

遭遇でクルートークンを得た場合、イベントカードをイベントカード捨て場へ置く。得なかった場合は、引いた山の上から裏向きのカード2枚を引き、イベントカードと混ぜてシャッフルし、3枚を元の山の上へ戻す。
