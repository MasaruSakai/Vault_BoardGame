# アーカムホラー 第3版

## 舞台とプレイヤー

1926年、狂騒の20年代のマサチューセッツ州アーカムが舞台。H・P・ラヴクラフトのクトゥルフ神話を題材に、時間と空間を越えた異形の存在、エンシェントワンの脅威に立ち向かう。

1〜6人で遊ぶ協力型ボードゲームで、プレイ時間はおよそ2〜3時間。プレイヤーは探索者を担当し、全員で1つのチームとして勝敗を共有する。

## ゲームの目的

探索者はアーカムの街を移動し、場所や人々との遭遇を解決する。遭遇から得たクルートークン（手がかり）を調査し、物語カードに示される目的を達成してシナリオを進める。

一方、破滅トークンが増えるとアーカムの状態が悪化し、物語カードに示された敗北条件へ近づく。探索者は手がかりを集め、モンスターや超自然的な脅威を退け、エンシェントワンの行動を阻止する。

## ラウンドの全体像

ゲームは、終了条件が満たされるまで次の4フェイズを繰り返す。

1. [アクションフェイズ](rounds-and-actions.md#アクションフェイズ)
2. [モンスターフェイズ](encounters-and-monsters.md#モンスターフェイズ)
3. [遭遇フェイズ](encounters-and-monsters.md#遭遇フェイズ)
4. [神話フェイズ](mythic-phase.md#神話フェイズ)

公文書置き場に置かれた物語カードが、現在のシナリオの目的、追加ルール、勝利・敗北条件を決める。
