# 探索者一覧

## 読み方

画像番号は、Sourcesにある原画像の番号である。偶数ページが能力値・固有能力、直後の奇数ページが物語・役割・開始時所持品になっている。能力値は、`知識／影響力／観察力／筋力／意志力` の順で記載した。

開始時所持品カードの効果は、[開始時所持品カード](../reference/starting-item-cards.md)にまとめている。探索者全般の敗北、役割、助力カードのルールは[探索者とカード](investigators-and-cards.md)を参照。

以下の「探索者別詳細」は、このページだけで候補を比較できるように、能力値、固有能力、開始時所持品のカード本文を再掲したもの。カードの種類、アイコン、原画像も確認したい場合は、各カード名または[開始時所持品カード一覧](../reference/starting-item-cards.md)を参照。

## 探索者別詳細

<a id="dexter-drake"></a>
### デクスター・ドレイク

* **能力値**：体力5／正気度7。知識4／影響力3／観察力2／筋力2／意志力2。集中上限：所持する呪文カードの枚数。
* **固有能力「魔法のオーラ」**：1ラウンドに1回、知識判定中、ダイスを1個または全部振りなおしてもよい。
* **固定で得るもの**：
  * 《ルルイエの霧》 — 回避アクションの一部として観察力判定を行うとき、かわりに知識判定を行ってもよい。モンスターの回避修正は通常どおり適用する。
  * 2ドル。
* **以下から選ぶ**：
  * 《アストラル投射》 — 通常の移動アクションのかわりに知識判定を行い、成功数+2マスまで移動してもよい。
  * 《奇術師の杖》 — 呪文を唱えるとき、知識+2。

<a id="michael-mcglenn"></a>
### マイケル・マクグレン

* **能力値**：体力8／正気度4。知識2／影響力3／観察力1／筋力4／意志力3。集中上限：1。
* **固有能力「返報」**：攻撃アクションの一部としてモンスター1体を敗北させたとき、正気度を1点回復するか、任意のスキルの集中トークンを1個得てもよい。
* **固定で得るもの**：
  * 《トンプソン》 — 攻撃アクション中、筋力+4。
  * 3ドル。
* **以下から選ぶ**：
  * 《オバニオン一味》 — 収入アクション後、筋力判定を行ってもよい。成功すれば2ドル得る。
  * 《蒸気自動車》 — 移動アクション後、交戦状態のモンスターに2点のダメージを与えてもよい。そうしたなら、このカードにも2点のダメージを与える。

<a id="daniela-reyes"></a>
### ダニエラ・レイエス

* **能力値**：体力7／正気度5。知識3／影響力3／観察力1／筋力3／意志力3。集中上限：3。
* **固有能力「仕事好き」**：収入アクションを行ったあと、任意のスキルの集中トークンを1個得てもよい。
* **固定で得るもの**：
  * 《ガブリエル》 — 通常の移動アクションのかわりに3マスまで移動できる。さらに1ドル消費すれば、もう1マス移動できる。
  * 3ドル。
* **以下から選ぶ**：
  * 《剣の1（タロット）》 — ダイスを1個振りなおすために集中トークンを1個消費した場合、さらに正気度を1点回復してもよい。
  * 《レンチ》 — 攻撃アクション中、筋力+1。使用中のカードのうち、手のアイコンがあるものがこのカードだけなら、+1ではなく+3。

<a id="agnes-baker"></a>
### アグネス・ベイカー

* **能力値**：体力6／正気度6。知識4／影響力2／観察力2／筋力2／意志力3。集中上限：2。
* **固有能力「血の呪術」**：呪文を唱えるとき、恐怖を受けるかわりにダメージを受けてもよい。呪文を唱えるとき、ダメージを1点受けるか遺物トークンを1個消費したなら、知識+2を得る。
* **固定で得るもの**：
  * 《ハイパーボリアの秘宝》 — 呪文を唱えたあと、任意のスキルの集中トークンを1個得てもよい。
  * 3ドル。
* **以下から選ぶ**：
  * 《精霊の嵐》 — 攻撃アクションの一部として筋力判定を行うとき、かわりに知識判定を行ってもよい。モンスターの攻撃修正は通常どおり適用する。
  * 《肉体の護り》 — 1ラウンドに1回、自分または任意の場所にいる別の探索者・協力者がダメージを受けるとき、知識判定を行い、成功数分のダメージを防ぐ。

<a id="wendy-adams"></a>
### ウェンディ・アダムス

* **能力値**：体力5／正気度7。知識3／影響力1／観察力4／筋力2／意志力3。集中上限：3。
* **固有能力「近道」**：追加のアクションを行う前または後に、2マスまで移動してもよい。これはフリーアクションとみなす。
* **固定で得るもの**：
  * 《ママの護符》 — 1ラウンドに1回、受けた1点のダメージまたは1点の恐怖を防ぐ。
  * 1ドル。
* **以下から選ぶ**：
  * 《パパ・ターソンさん》 — 1体以上のモンスターが攻撃してくる前に捨ててもよい。そうしたなら、それらすべての交戦状態を解き、消耗状態にして自分のいるマスに置く。
  * 《不思議な写真》 — クルートークンを1個得たあと、任意の集中トークンを1個得てもよい。取引で受け取ったクルーは「得る」ではなく「交換」なので、この条件を満たさない。

<a id="marie-lambeau"></a>
### マリー・ランボー

* **能力値**：体力5／正気度7。知識3／影響力4／観察力2／筋力2／意志力2。集中上限：2。
* **固有能力「スモーキー・ベルベットな声」**：1ラウンドに1回、アクションを行ったあと、任意のマスにいる他の探索者1人は、それと同じアクションを1回行ってもよい。交戦状態によるアクションの制限は適用される。
* **固定で得るもの**：
  * 《介入》 — 1ラウンドに1回、任意のマスの他の探索者が能力判定を行うとき、知識-1の能力判定を行い、成功数を対象の成功数に加えられる。遺物トークンを消費したとき、遺物トークンを1個得る。
  * 4ドル。
* **以下から選ぶ**：
  * 《魔女の血統》 — アクションとして、この手番中にすでに行ったアクション1つをもう一度行う。この特殊なアクションは、マリーの「スモーキー・ベルベットな声」で他の探索者に行わせてもよい。遺物トークンを1個消費したなら、1ラウンドに1回、遺物トークンを1個得る。
  * 《祖母のナイフ》 — 攻撃アクション中、筋力+2。呪文を唱えている間、知識+2。

<a id="minh-chi-phan"></a>
### ミン・チー・ファン

* **能力値**：体力6／正気度6。知識3／影響力3／観察力3／筋力2／意志力2。集中上限：2。
* **固有能力「仲間」**：1ラウンドに1回、能力判定中、自分または自分と同じマスにいる他の探索者1名は、自分のいる区域タイルに置かれたクルートークンの数までのダイスを振りなおしてもよい。
* **固定で得るもの**：
  * 《黄衣の王》 — 1ラウンドに1回、1点以上の恐怖を受けたとき、自分のクルートークン1個をシナリオシート上に置いてもよい。
  * 3ドル。
* **以下から選ぶ**：
  * 《分析的な頭脳》 — 所持する集中トークンが上限以上のとき、知識または観察力の能力判定中、ダイスを1個追加する。
  * 《共働》 — 集中トークンの所持上限を+1する。同じマスにいる他の探索者は、自分の集中トークンに対応するスキルをそれぞれ+1する。

<a id="calvin-wright"></a>
### カルヴァン・ライト

* **能力値**：体力6／正気度6。知識3／影響力3／観察力3／筋力3／意志力1。集中上限：2。
* **固有能力「莫逆の友」**：アクションとして、自分と同じマスにいる他の探索者や協力者と、任意の点数の体力／正気度トークンをやり取りしてもよい。
* **固定で得るもの**：
  * 《魂の短剣》 — 攻撃アクション中、筋力+2。浄化アクション中、知識+2。
  * 《時が終わるまで》 — このカードはいかなる状況になっても捨てられない。カード上から、同時発生効果でダメージトークンと恐怖トークンを1個ずつ取り除く。
  * 3ドル。
* **以下から選ぶ**：
  * 《使者の声》 — 恐怖を1点受けてもよい。そうしたなら、任意の数のダイスを振りなおせる。この能力は1回の結果につき1回のみ使用でき、《闇との盟約》で振ったダイスにも使用できる。
  * 状態カード《闇との盟約》1枚 — 同時発生効果でダイスを1個振る。1が出たならこのカードを裏返す（このダイスは判定ではない）。裏面の効果は複数種類あるため、実際に受け取ったカードの裏面を確認する。《使者の声》はこのカードで振ったダイスにも使える。公式紹介でも、裏面の効果が異なる複数の《闇との盟約》があると説明されている（[Fantasy Flight Games公式記事](https://www.fantasyflightgames.com/en/news/2018/10/5/the-pull-of-arkham/)）。

<a id="norman-withers"></a>
### ノーマン・ウィザーズ

* **能力値**：体力5／正気度7。知識3／影響力1／観察力3／筋力2／意志力4。集中上限：2。
* **固有能力「星々の中に」**：自分のいるマスから破滅トークンを2個以上取り除いたあと、恐怖を1点受ければ、自分の所持するクルートークン1個をシナリオシートの上に置ける。
* **固定で得るもの**：
  * 《ゲート探知》 — アクションとして知識判定を行い、成功すれば破滅トークンが1個以上あるマスのいずれかへ移動する。
  * 1ドル。
* **以下から選ぶ**：
  * 《天文学の本》 — 1ラウンドに1回、能力判定中、自分のいるマスに置かれた破滅トークンの数までのダイスを振りなおせる。
  * 《貴重な記念品》 — クルートークンを1個得たあと、このカード上から恐怖トークンを2個取り除く。

<a id="rex-murphy"></a>
### レックス・マーフィー

* **能力値**：体力7／正気度7。知識3／影響力3／観察力3／筋力2／意志力2。集中上限：無限。
* **固有能力「一族の呪い」**：能力判定時、6の出目のみを成功とみなす。また、決して祝福／呪縛状態にならない。
* **固有能力「決して諦めない」**：能力判定に失敗したあと、任意のスキルの集中トークンを1個得る。
* **固定で得るもの**：
  * 《真実の探求》 — クルートークンを1個得たあと、1ドル得る。さらに、任意の集中トークンを1個得てもよい。
  * 《塔（タロット）》 — 1ラウンドに1回、能力判定中、ダイスを1個または全部振りなおしてもよい。
  * 3ドル。
* **以下から選ぶ**：
  * 《一気に解き明かす》 — 調査アクション中、それぞれのダイスの出目に+1する。
  * 《確率を打ち負かす》 — 集中アクションで集中トークンを得るとき、任意の集中トークンをもう1個得てもよい。

<a id="jenny-barnes"></a>
### ジェニー・バーンズ

* **能力値**：体力7／正気度5。知識1／影響力4／観察力2／筋力3／意志力3。集中上限：1。
* **固有能力「信託資金」**：アクションとして、自分が所持しているお金トークンが2ドル以下の場合、3ドル得る。
* **固定で得るもの**：
  * 《イザベルを探して》 — 1ラウンドに1回、能力判定の解決時にダメージ1点と恐怖1点を受けてもよい。そうしたなら、任意の数のダイスを振りなおす。
  * 5ドル。
* **以下から選ぶ**：
  * 《着飾る》 — ダイスを1個振りなおすために集中トークンを1個消費した場合、1個ではなく任意の数のダイスを振りなおしてもよい。探索者シートの「信託資金」を使うとき、追加で2ドル得る。
  * 《ジェニーの2丁拳銃》 — 攻撃アクション中、筋力+3。攻撃アクションの一部としてダイスを振ったとき、出目の1つに+1してもよい。

### トミー・マルドゥーン
